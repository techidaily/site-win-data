### Everything New, Changed, and Fixed in LYRX 1.18

* New Audio Engine upgrade for Windows audio output system using WASAPI (new implementation) or ASIO (DirectSound discontinued)
* Big quality increase for “High-quality time-stretching” option (Key Lock and Key Stepping)
* New for both Mac and Windows: added extra input device for microphone because sometimes users have separate USB mics: “Select an additional audio device for microphone input (optional)”
* Windows, Mac: fixed not-working or bad audio quality for “Select an additional audio device for previewing / monitoring (headphones)”
* Windows, Mac: changed latency setting to power-of-two sizes (64, 128,…,4096) which corresponds to (1.45 ms, 2,9 ms,…,92.9 ms). Please note that on Windows you can only control the latency for ASIO, WASAPI latency is controlled by the OS itself (usually about 22 ms) and cannot be adjusted (it’s fixed).
* Mac: fixed audio inputs / microphone bad quality because of resampling bug
* Mac: fixed unnecessary audio output resampling (very slight audio quality improvement)
* Windows: fixed pre-selecting the default audio device at the 1st run
* Removed 3rd-party services tracks from the search results if they are not truly active
* Automatically clear decks video output when audio-only content is loaded (eg. after loading a video/karaoke track and then loading an audio track the last video frame was still showing)
* Mac: minimum requirements are now macOS 10.15 (Catalina) or newer
* Various performance improvements

**IMPORTANT NOTE:** in some cases, you may need to re-apply your audio routing settings after installing version 1.18\. You will see a warning (plus instructions) displayed on screen if the current settings are not properly configured.
